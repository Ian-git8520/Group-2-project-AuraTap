# Quick Start Guide

## Prerequisites
- Python 3.8+ (for backend)
- Node.js 14+ (for frontend)
- npm or yarn

## Running the Application

### Option 1: Unix/Mac (using bash scripts)

**Terminal 1 - Start Backend:**
```bash
cd backend
chmod +x run.sh
./run.sh
```

**Terminal 2 - Start Frontend:**
```bash
cd frontend
chmod +x run.sh
./run.sh
```

### Option 2: Windows (using batch scripts)

**Command Prompt 1 - Start Backend:**
```batch
cd backend
